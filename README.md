# UNITEC Bolsas — site para GitHub Pages

## Como publicar
1. Baixe e extraia este ZIP.
2. No GitHub, abra o repositório `unitecjd1/unitec-bolsas`.
3. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md` para a raiz do repositório (substituindo os arquivos antigos, se solicitado).
4. Faça o commit das alterações.
5. Em **Settings → Pages**, mantenha a publicação pela branch principal (`main`) e pasta `/ (root)`.

O site é estático e não precisa de instalação ou servidor.

## Ajustar o WhatsApp
Os botões usam um link genérico `https://wa.me/`. Para direcionar ao WhatsApp da escola, edite os links em `index.html` e substitua o endereço pelo número com código do país e DDD, somente números. Exemplo: `https://wa.me/5511999999999`.
